# Ordliste

| Ord | Betydning |
|---|---|
| **Avhengighet** | At et løp henter data fra eller leverer data til en annen statistikk, et register eller en ekstern. Tegnes med stiplet grå strek i 3.0 |
| **AS IS** | Dagens løp, slik det faktisk er |
| **B5, B6, B7** | Malene i kartleggingen av komplekse statistikker: dagens produksjonsløp (B5), fremtidig løsning og behov (B6), og funksjonalitet, der det avklares om noe finnes eller må utvikles (B7) |
| **Bakkesystem** | System som kjører på SSBs egne servere, for eksempel SAS, FAME og Oracle, i motsetning til skyplattformen Dapla |
| **Dapla** | SSBs dataplattform i skyen |
| **Datatilstand** | En vedtatt, stabil tilstand for lagring av data i Dapla: kildedata, inndata, klargjorte data, statistikk og utdata. Merkes K, I, KL, S og U |
| **Datatype** | Hva slags data et datasett er: metadata, mikrodata, makrodata, statistikk eller utdata. Vises i kjernen av datasymbolet |
| **Fase** | En av de fire hovedprosessene fra GSBPM som Dataflyt bruker: samle inn, klargjøre, analysere og formidle |
| **Fokus (nivå 2)** | Tegning av ett prosessteg med alle systemer og datasett |
| **GSBPM** | Generic Statistical Business Process Model, den internasjonale modellen for statistikkproduksjon |
| **Kildemerke** | Opplysning om hvor et felt i modellen kommer fra: D1, D2, D3, 2.0, workshop eller tolkning |
| **Kvalitetssikringsliste** | Liste over det som er tolket eller ikke bekreftet, fordelt på hvem som må bekrefte |
| **Linse** | En variant av oversikten som framhever det én beslutning trenger, for eksempel plattform og frist |
| **Merge** | At flere elementer går videre til samme element |
| **Modell** | Beskrivelsen av et løp som data (YAML i 3.0, Excel i 2.0). Tegningene lages fra den |
| **Nivå 3, detalj** | Tegning av hva som skjer inne i ett system |
| **Oversikt (nivå 1)** | Tegning av hele løpet som 5–10 prosessteg |
| **Plattform** | Systemet eller verktøyet et steg kjører på, for eksempel SAS, FAME, Excel eller Dapla |
| **Prosessteg** | En gruppe systemer og datasett som sammen gjør én ting som kan beskrives med én setning |
| **Rammeverkssystem** | System utviklet av andre enheter, der fagseksjonen ikke kan endre koden. Med meny: seksjonen kan tilpasse noe |
| **Skill** | Samling instruksjoner som lærer Claude en arbeidsmetode. ssb-dataflyt er skillen for Dataflyt 3.0 |
| **Skreddersydd kode** | System som fagseksjonen har utviklet selv og kan endre |
| **Split** | At ett element går videre til flere elementer |
| **TO BE** | Målbildet, slik løpet skal være i Dapla |
| **Utdata** | Formidlet statistikk som er åpent tilgjengelig. Tegnes med «blader» |
